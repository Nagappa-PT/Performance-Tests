Test Result

The SecGenie Scans List API completed baseline performance testing.

Why Issue Occurs (Root Cause & Error Analysis)

  • Unpaginated Historical Query: Retrieving all past scan execution records with embedded target and tool summaries induces memory pressure.
  • Unindexed Timestamp Ordering: Sorting large scan histories by started_at DESC causes temporary file sorting in relational databases.

How to Resolve (Optimization & Remediation Steps)

  • Enforce mandatory pagination parameters (e.g. ?page=1&size=20).
  • Create composite index on (tenant_id, status, started_at DESC).
  • Cache active scan execution lists in Redis key scans:list.
